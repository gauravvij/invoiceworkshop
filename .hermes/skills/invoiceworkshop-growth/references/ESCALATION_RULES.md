# Escalation Rules

Contact the owner ONLY when it genuinely matters. Routine operations continue
independently; do not page for day-to-day status.

## Escalate (owner contact) when
- Google penalty / manual action / substantial indexing collapse
- Security incident
- Analytics/Measurement suddenly failing (all sockets empty/403)
- Domain / email / account problem
- Outreach complaint or legal/trademark concern
- Any proposed paid expenditure or sponsorship (Level-2)
- Any major architecture / new URL / deploy decision (Level-2)
- New opportunity genuinely requiring founder identity/interview
- Repeated workflow failure (same job fails three consecutive runs without progress)

Escalations are written as a short, factual summary (`what | evidence | request`),
sent to the owner only. A 1-page brief is attached.

## When NOT to escalate
- Routine measurements, snapshot diffs, prospect scoring, placement verification,
  standard cadence; channel working notes; a single 4xx that resolves.
- A newly launched priority URL that is discovered but not yet indexed, unless an indexed
  URL later drops out or the state materially worsens across consecutive observations.
- A missing optional credential: log a readiness note and run the scriptable remainder.

## Rule of thumb
- If the owner can act on it immediately, escalate.
- If it's just status, don't.
